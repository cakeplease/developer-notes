


#nano
Search:
**Ctrl + W** 

Search and replace:
**Ctrl + W, Ctrl + R** 

While reading a file (using |), you can **search** after words by typing **/** followed by search phrase. **n** for next match and **N** for previous match.


#terminal
See a list of previously executed commands:
**history**

Execute specific command:
**!`<command number>`**

Or **Ctrl + R** for search in history (the quickest way)

Clear current line:
**Ctrl + U**
