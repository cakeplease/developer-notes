# #Authentication and #authorization

Nais helps your app with logging in users, validating inbound requests and making authenticated outbound requests using the following identity providers:
- entra ID
- ID-porten
- tokenX
- maskinporten


# Logging in users
🧍 Log in _employees_  [Entra ID](https://docs.nais.io/auth/entra-id/)

🧍 Log in _citizens_  [ID-porten](https://docs.nais.io/auth/idporten/)
