Cloud Run Service vs Job vs Function vs Worker pools

Hierarchy
Project -> Service -> Revision -> Instance

## #Service
A service exposes a unique endpoint and automatically scales the underlying infrastructure to handle incoming requests.

Deploy a container image, source code or a function to create a service.

## #Job
A job executes tasks to completion. Jobs are ideal for batch processing, data analytics, and machine learning workloads.

## #WorkerPool
A worker pool provides flexible compute for non-HTTP request workloads. Deploy a container image or source code to create a worker pool.
