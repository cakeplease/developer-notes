Horizontal Pod Autoscaler (HPA)

Deployment vs ReplicaSet

ReplicaSet 
- ensures the right number of pods are always running
- recreates pods if they fail
- represents one version of microservice
- updating the deployment image creates a new ReplicaSet

Deployment
- one deployment represents all versions of microservice
- ensures smooth, zero-downtime releases

## Scaling
HPA vs VPA

#HPA - pod-level (horizontal) - scales number of pod replicas based on load. Build-in feature
#VPA - pod-level (vertical) - scales CPI/memory of each pod - recommends/updates CPU/memory resource requests & limits for pods, instead of adding replicas - not build-in, has to be installed separately
**Cluster level** - number of nodes in cluster
