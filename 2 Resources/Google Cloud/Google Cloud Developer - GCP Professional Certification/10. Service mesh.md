Service mesh is a layer that handles common micro-service features automatically. 
Goal:
Off-load security, observability and reliability concerns from application code.

How it works:
- Control plane - configures and manages proxies
- Data plane - proxy beside each container, handles all common features for micro-services


Istio - popular open source service mesh
Integrates seamlessly with Kubernetes
Result: micro-services can focus on business logic


Google Service Mesh
Google's fully managed service mesh.
Features:
- traffic management
- observability
- security

SLO - service level objectives
