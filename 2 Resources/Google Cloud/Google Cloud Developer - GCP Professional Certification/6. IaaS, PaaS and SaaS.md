
## IaaS - insfrastructure as a service
Concept: use only infrastructure from the cloud provider

Customer responsibility: high
Components: OS, runtime, and system software
Operations: availability, durability and scaling


## PaaS - platform as a service
Concept: use a complete platform provided by the cloud

Cloud provider responsibility: high
Components: OS, runtime, availability, durability, scaling

Customer responsibility: low
Focus: code, data and config


## SaaS - software as a service
Concept: centrally hosted software

Billing: offered on a. subscription basis

Service provider is responsible for almost everything

Customer: usage

Ex.: gmail
